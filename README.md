# HR Employee Survey Dashboard

## Project Overview
This project analyzes employee satisfaction and engagement using Microsoft Power BI. The dashboard provides insights into employee responses, satisfaction levels, departmental performance, and key areas requiring improvement.

## Objectives
- Measure employee satisfaction levels.
- Identify departments with the highest satisfaction scores.
- Highlight areas needing improvement.
- Analyze employee response distribution.
- Support HR decision-making with data-driven insights.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- Data Visualization
- Data Analysis

## Dashboard Features
- KPI Cards
- Top Survey Questions by Satisfaction
- Top 10 Departments by Employee Satisfaction
- Areas Needing Improvement
- Employee Response Distribution

## Key Insights
- Most employees reported positive satisfaction levels.
- Certain survey questions consistently received high ratings.
- Some areas require targeted improvement initiatives.
- Departmental satisfaction varies across the organization.
